## ◈ Featured Projects

<details>
<summary><b>⬡ &nbsp;Farm Fresh — B2B2C Agricultural Marketplace</b></summary>

<br/>

> A full-stack B2B2C marketplace directly connecting rural farmers with commercial bulk buyers — eliminating middlemen, preventing distress selling, and enabling fair, data-driven agricultural trade at scale.

<br/>

| Attribute | Detail |
|:---|:---|
| **Stack** | React.js · Vite · Node.js · Express · MongoDB · Tailwind CSS · JWT |
| **Architecture** | RESTful API · Role-Based Access Control · Geospatial Indexing (2dsphere) |
| **Performance** | Compound indexes for heavy search optimization · localized sourcing via geo-queries |
| **Security** | JWT token management · Bcrypt password hashing · RBAC for farmer and buyer roles |
| **Impact** | Addresses the agricultural distress selling problem by enabling direct B2B procurement channels |
| **Repository** | [![GitHub](https://img.shields.io/badge/Farm--Fresh-7C3AED?style=flat-square&logo=github&logoColor=white)](https://github.com/AtikshSingh007/Farm-Fresh) |

<br/>

Farm Fresh was built to solve a real socioeconomic problem — rural farmers in India lose a significant portion of revenue to intermediaries. The platform provides a dedicated marketplace where farmers can list produce and bulk buyers can source locally using geospatial proximity queries. MongoDB's `2dsphere` index powers location-based discovery, while compound indexes ensure performant search even at scale. The authentication layer uses JWT with HTTP-only cookies and Bcrypt hashing, with RBAC cleanly separating farmer and buyer capabilities at the API level.

<br/>
</details>

<details>
<summary><b>⬡ &nbsp;DSVisualizer — Interactive Data Structure & Algorithm Visualizer</b></summary>

<br/>

> A full-stack educational platform providing real-time, step-by-step visualizations of complex data structures and algorithms — with a special focus on Dynamic Programming, custom code execution, and execution trace rendering.

<br/>

| Attribute | Detail |
|:---|:---|
| **Stack** | React.js · Vite · Node.js · Express · MongoDB · Monaco Editor · Vanilla CSS |
| **Architecture** | Custom execution engine · state transition tracker · Monaco Editor integration |
| **Performance** | Real-time step-by-step animation · sub-100ms state update propagation |
| **Features** | Dynamic Programming visualizer · CSES problem set support · custom user code execution |
| **Impact** | Lowers the barrier to understanding complex algorithms — targeted at CP learners and CS students |
| **Repository** | [![GitHub](https://img.shields.io/badge/DSVisualizer-7C3AED?style=flat-square&logo=github&logoColor=white)](https://github.com/AtikshSingh007/DSVisualizer) |

<br/>

DSVisualizer was born out of the frustration of learning Dynamic Programming without visual feedback. The platform's custom execution engine dynamically tracks state transitions, array mutations, and subproblem dependency graphs — rendering them as interactive, step-through animations in the browser. The Monaco Editor integration gives users a full-featured coding environment to write custom logic, define inputs, and instantly observe execution traces. Classic CSES problems are pre-loaded for guided practice.
